## Fonts

Anthropic font names are used to identify compatible locally installed fonts. Anthropic retains all rights to its typefaces. No Anthropic font binaries are distributed in this repository or its release archive. The MIT license covers this project's code and theme data, not the fonts.

The optional downloader retrieves the OTF files identified in `font-sources.json` from `https://assets.claude.ai/Fonts/`. These source URLs were checked on October 30, 2026. URLs may change; downloads fail if the pinned size or SHA-256 checksum does not match.

The community resource [Isilsolme/dsh-anthropic-fonts](https://github.com/Isilsolme/dsh-anthropic-fonts) helped identify the optional Mono family. Its [font notice](https://github.com/Isilsolme/dsh-anthropic-fonts/blob/main/LICENSE) explicitly excludes its font files from the MIT license. This project does not redistribute or automatically download those community files.
